## Setup checklist

1. Claim the handle, set display name, bio, location and website.
2. Upload `avatar.png` and `banner.png`.
3. Turn on 2FA before you post anything. A launch account with traction is a
   phishing target.
4. Post the launch tweet **with the video attached**, then pin it.
5. Add replies 1–5 underneath as a thread.
6. Tag the official OKX account in a reply, not in the main post — a tag in the
   body reads as begging, a tag in a reply reads as informing. **Check the real
   handle yourself**; I could not verify it and guessing a wrong one is worse
   than omitting it.

## One rule to be aware of

If you ever automate the replies — a bot that answers every "reply with a plan"
by hitting the API — X requires automated accounts to disclose that they are
automated. Doing it by hand needs no label. Worth knowing before you wire
anything up, because unlabelled automation is a suspension risk, and losing the
account mid-judging would be an expensive way to save time.
